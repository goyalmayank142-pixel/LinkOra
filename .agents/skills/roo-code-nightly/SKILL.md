# Roo Code Nightly — Agent Controller

Roo Code allows switching the agent's behavior and tool permissions dynamically between specialized personas:

## Built-In Modes
1. **Architect Mode**: Use for architectural decisions, system blueprints, API contracts, and technology selection before code is written.
2. **Code Mode**: Use for feature development, bug fixing, and refactoring.
3. **Debug Mode**: Use when diagnosing complex exceptions, analyzing logs, and isolating regressions.
4. **Ask Mode**: Use when answering questions about the codebase without making any file changes.
5. **Test Mode**: Use for generating unit, integration, and end-to-end test suites.
