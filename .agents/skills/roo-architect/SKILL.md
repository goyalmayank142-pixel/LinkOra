# Roo Code Architect Mode

When operating in Architect mode:
- Gather functional requirements and non-functional constraints.
- Formulate component architectures and data flows.
- Define data schemas, database migrations, and REST/GraphQL/tRPC contracts.
- Present architectural options with clear trade-offs before generating code.
