# Roo Code Debug Mode

When operating in Debug mode:
1. Capture exact reproduction steps and error logs.
2. Formulate testable hypotheses regarding root causes.
3. Inspect relevant source files and git history to isolate when the regression was introduced.
4. Verify the fix with an automated test before closing the issue.
